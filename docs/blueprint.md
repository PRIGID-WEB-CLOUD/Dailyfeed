# **App Name**: BlogAdminLite

## Core Features:

- Post Management: Create, edit, and delete blog posts via a simplified interface. Minimalistic CRUD (Create, Read, Update, Delete) functionality for posts.
- Rich Text Editor: A basic rich text editor for formatting content with essential styling options such as bold, italics, lists, and headings.
- Media Library: Upload, manage, and insert images into blog posts. Basic media management capabilities.
- Category and Tag Organization: Assign categories and tags to posts for improved content organization and discoverability.
- User Authentication: Secure user login and authentication functionality.
- SEO Tool Assistant: AI tool to help provide title and meta description suggestions.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to evoke a sense of calm and sophistication suitable for content creation.
- Background color: Very light grayish-lavender (#F5F5FF).
- Accent color: Dusty purple (#A9A9D1) for interactive elements and call-to-actions to draw the user's eye without overwhelming the softer color scheme.
- Headline font: 'Playfair', a modern serif font.
- Body font: 'PT Sans', a humanist sans-serif font. Note: currently only Google Fonts are supported.
- Simple, line-based icons to represent actions and categories within the dashboard.
- Clean, minimalist layout with a focus on content. Ample white space and clear visual hierarchy.
